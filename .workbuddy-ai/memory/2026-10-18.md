## 经验教训
- UseWindowsForms=true 会把 WPF 与 WinForms 的同名类型都拉进全局 using，~20 个名字要 alias
- 沙箱 git push 走不通时，blob→tree→commit→PATCH ref 是可靠 fallback
- 写多文件 XAML 项目时，模块级 dotnet build 失败要立即用 Edit 精修，不能批量 Write 触发循环保护
- 视觉验证要早做（Module 3 第一次截屏就知道渲染对了），后续模块可沿用同一套 Pegged.exe 冒烟
