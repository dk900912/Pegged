1. **双击预览打不开**：`PreviewMouseLeftButtonDown` 中 `CaptureMouse()` 破坏 WPF `MouseDoubleClick` 检测 → 改用手动跟踪 `_lastClick` 时间戳（400ms 内二次点击触发预览）

用户再次要求真实双击+端到端+UI核对。上一轮结论过度声明（编译过≠功能过）。

**实际发现并修复（均有实证）**
1. 双击启动后挂绳窗停在 (96,96)、感应条 (32,32)：`PlaceOn()` 在 `Show()` 前调用，`MoveTo()` 句柄为0时静默 return。修：显式 `SetProcessDpiAwarenessContext(PerMonitorV2)` + `OnSourceInitialized` 补定位 + 用目标屏 scale。
2. 默认设置下挂绳**永不展开**：`IsFullScreen()` 枚举所有窗口，Windows 常驻 Program Manager 与 IME 宿主满屏 → 永远判"有全屏应用"。修：只看前台窗口 + 跳过 cloaked/TOOLWINDOW/NOACTIVATE + 比 Physical 矩形。
3. 重复启动出现第二套窗口 → 命名 Mutex 单实例。
4. 裁剪窗 8 手柄不可拖（父 Canvas `IsHitTestVisible=False`）+ `Children[i+1]` 越界崩溃 → 重写 CropWindow。
5. 拖拽 Esc 把卡片当 Move 删除 → None 不再回退成 initial。
6. 全局热键随设置窗关闭失效 + 失败 hook 泄漏 → 收归 App 常驻，Register 返回 bool。
7. 空绳微风不播（`OnFrame` 的 `AtRest` 早退）；感应条 4s→2.4s、0.55-0.90→0.35-0.75；首启 4s→5s。
